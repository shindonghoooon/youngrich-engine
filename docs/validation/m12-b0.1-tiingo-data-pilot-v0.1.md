## Corporate-action semantics

Independent raw-close normalization matched `adjClose` returns for:

- AAPL 4:1 split
- NVDA 4:1 split
- TSLA 5:1 and 3:1 splits
- SKLZ 1:20 reverse split

The comparison directly matches raw split-normalized return to adjusted return, so real
same-session moves—including TSLA's approximately 12.6% move—are not treated as
adjustment failures.

For AAPL, NVDA, SPY, and VTI, 24 dividend observations per symbol matched the raw
cash-inclusive return convention to `adjClose`; maximum observed return error was below
`2e-11`.

Result for Tiingo request version `tiingo-eod-v0.1`:

- raw close + `splitFactor` → `SPLIT_ADJUSTED`: validated for research
- provider `adjClose` → `TOTAL_RETURN_ADJUSTED`: validated for research
- provider selection for production: not approved

## Identity and terminal-outcome gaps

not reliable enough for a historical security master. Exact TWTR and VLDR stock matches
were absent; BBBY exposed current/reused and BBBYQ identities; and active flags did not by
themselves establish historical membership. Metadata end date and last price were not
treated as terminal payoff.
